# datavid — ranked 3D tower data films

Renders a 3:00 (default) 1080p30 documentary from a dataset: 12 s intro, one item every ~1.46 s, finale on the #1 item, end card with the total. All pixels and all audio are generated by the bundled Python code; the only binary inputs are the bundled fonts.

## Inputs you need

A topic is enough to start; the job is then to turn it into a ranked dataset.

| Field | Meaning |
|---|---|
| `items[].name` | display name (rendered uppercase) |
| `items[].value` | the single ranked number (USD billions, metres, users…) |
| `items[].category` | short kicker, e.g. `TECHNOLOGY`, `OFFICE` |
| `items[].meta` | second line, e.g. `TESLA · SPACEX · UNITED STATES` |
| `total` | optional sum used on the end card; omit to auto-sum |

Items are sorted ascending automatically: the first item becomes **rank 1** (smallest) and the last becomes **rank N** (largest). This matches "start at #1 and climb to #100".

## Workflow

1. **Research the data.** Find one authoritative ranked list with a snapshot date (Forbes, CTBUH, CompaniesMarketCap, UN, league tables…). Collect N items with name + value + one category + one meta line. Never invent numbers; put the source and snapshot date in `source_line` and `source_note`. For 100 items, a JSON API or a scraped table is faster than reading articles — see `references/data-sourcing.md`.
2. **Pick N and duration.** `duration = 34 + N × seconds_per_item`. Defaults: 1.46 s per item, so N=100 → 180 s, N=50 → 107 s, N=12 → 51.5 s. Stay between 1.2 and 1.6 s per item; below 1.2 s names cannot be read.
3. **Create the project:** `python3 scripts/new_project.py /path/to/project` (copies `config.json` + `data.json` templates).
4. **Fill `data.json` and `config.json`** — see the config table below. Money example: `value_prefix "$"`, `value_suffix "B"`, `value_decimals 1`, `long_suffix " BILLION"`, `scale_max 800`.
5. **Render stills first:** `python3 scripts/render.py --project /path --stills 3 8 18 40 150 162 176`. Inspect every still at full size. Fix config, not code.
6. **Full render:** `python3 scripts/render.py --project /path --workers 6`. On 6 cores this is ≈0.31 s/frame/worker, so 5400 frames ≈ 5 min. It writes segments, concatenates, generates `out/score.wav` and muxes `out/<output_name>`.
7. **Normalise loudness** (video stream is copied, so this is fast and lossless):
   `ffmpeg -i out/video.mp4 -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:v copy -c:a aac -b:a 192k out/video_norm.mp4`
   Two-pass is better: measure with `print_format=json`, then pass `measured_*` with `linear=true`.
8. **Verify with ffprobe** (duration, 1920×1080, 30 fps, frame count, audio) and spot-check frames at 0.2 s, the middle, and the last second.
9. **Deliver the MP4** plus a preview still.

## config.json keys

| Key | Default | Notes |
|---|---|---|
| `brand` | — | top-left line, e.g. `FORBES  WORLD'S  BILLIONAIRES  2026` |
| `title_top` / `title_big` / `title_sub` | — | intro card; long words auto-shrink |
| `lower_kicker` / `lower_mid` / `source_line` | — | intro lower third |
| `scale_label` / `scale_max` | `VALUE SCALE` / auto | bottom-right scale; auto rounds max up to 200s |
| `value_prefix` / `value_suffix` / `value_decimals` | `$` / `B` / 1 | on-tower and card formatting |
| `long_suffix` | ` BILLION` | used by the finale value line |
| `finale_kicker` / `finale_lines` | `WORLD  #1` / 3 lines | right-hand title block |
| `finale_stats` | auto | `[["3.3x","THE NEXT PERSON"],["$7.12T","ALL 100 COMBINED"]]`; auto computes ratio and total |
| `end_title` / `end_total` / `end_caption` / `source_note` / `credit` | — | end card; `end_total` auto-formats the total |
| `gamma` | 0.72 | height curve; 1.0 = linear, lower = flatter |
| `seconds_per_item` / `duration` | 1.46 / auto | set `duration` to force an exact length |
| `colors` / `color_positions` | blue→cyan→violet→rose→gold | ramp by log-value position |
| `output_name` / `crf` / `preset` | `video.mp4` / 18 / veryfast | encode settings |

## Height scale

`h = 3.1 + 27 · (value / max)^gamma`. With `gamma < 1` the tallest item does not dwarf the rest (Musk is 33× the #2 person; linear height would flatten 99 towers into a line). Heights are strictly increasing with value, and the tower order is exact. If the user asks for true proportions, set `gamma: 1.0` and raise `seconds_per_item` so short towers stay readable.
