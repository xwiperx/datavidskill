# Portrait coverage — richest-2026

The project contains 100 ranked people and 61 locally cached portrait assets retained after conservative review; 39 portrait cards are intentionally blank. Retained manifest entries still require source-page verification before claiming exhaustive identity certification.
The per-image manifest, including source page, license, artist/credit, match method and local file path, is `image_sources.json`. Preserve it and comply with each license when redistributing.
